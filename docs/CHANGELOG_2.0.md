# 2.0 修复记录

- 默认入口改为中文桌面界面，保留 CLI 和旧终端引导。
- 新增统一合并流程，界面、CLI 和交互模式共享字段验证、输出保护和错误报告。
- 修复中文表单字段显示问号；嵌入 CJK 字体，并校验输出后的 canonical field value。
- 识别文本、选择、勾选字段；签名域不作为可写数据字段。
- 文本替换先收集原样式、统一删除占位符，再写入数据，保留邻近文字与图形。
- 支持带空格占位符；文字过长和多行内容返回明确错误。
- PDF 使用同目录临时文件和原子替换，异常不留下半份文档。
- 新增字段映射、记录预览、多页预览、后台生成、取消和结果列表。
- 重名文件自动编号；清理命名规则中的无效路径字符与 Windows 保留名。
- 统一处理缺失值，避免输出 `nan`；CSV/Excel 文本编号保留前导零。
- XLS 使用 xlrd；修正 GB18030 编码分支，取消乱码风险较大的 Latin-1 静默回退。
- `--validate-only` 无输出副作用；数据/模板/映射验证通过后才处理目录。
- `--clean` 拒绝清空根目录、当前目录、home、其上级及输入文件所在目录。
- ZIP 只归档本批次结果；通用 ZIP 工具排除自身并拒绝路径穿越。
- 目录可写性检查使用唯一临时文件，避免覆盖现有 `.write_test`。
- 新增可复现依赖清单、便携构建脚本、离线成品自检及 Windows CI。

历史文档 `USER_GUIDE_CN_V2.md`、`QUICK_START_CN.md` 与根目录旧报告描述的是旧命令行版本；当前操作以根目录 README 为准。
